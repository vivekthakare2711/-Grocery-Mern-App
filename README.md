## 🧠 About the Project 🧩

The **Grocery MERN App** is a full-stack application that simulates an **online grocery system**, where users can:

🛍️ View grocery items  
➕ Add new products  
✏️ Update existing items  
🗑️ Delete products  
📦 Manage data efficiently using MongoDB  

This project reflects **practical implementation of MERN stack concepts** and backend-frontend integration.
